⚡ 5-MINUTE SETUP
------------------

Step 1️⃣ : Create Supabase Project
  → Go to https://supabase.com
  → Click "New Project"
  → Fill in Name, Password, Region
  → Wait for setup (1-2 min)

Step 2️⃣ : Create teams Table
  → In Supabase Dashboard, go to "SQL Editor"
  → Copy SQL from SUPABASE_QUICK_START.md (lines 23-31)
  → Click "Run"
  → ✅ Table created

Step 3️⃣ : Get Credentials
  → Go to "Settings" → "API"
  → Copy "Project URL" and "Anon Key"
  → Keep them safe!

Step 4️⃣ : Configure .env.local
  → Open basket-lviv/.env.local
  → Add these lines:
  
    NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here

  → Save file

Step 5️⃣ : Test
  → Terminal: npm run dev:safe
  → Wait for "compiled successfully"
  → In another terminal, run:
    
    curl -X POST http://localhost:3006/api/teams/add \
      -H "Content-Type: application/json" \
      -d '{"name":"Test Team"}'

  → ✅ If you see {"success":true, "data":{...}}, it works!

📡 API ENDPOINT
---------------

Endpoint: POST /api/teams/add

Request body:
  {
    "name": "Team Name",
    "description": "Optional description",
    "photoUrl": "https://example.com/team-photo.jpg"
  }

Response (success):
  {
    "success": true,
    "data": { "id": 1, "name": "Team Name", ... },
    "message": "Team added successfully"
  }

Response (error):
  {
    "success": false,
    "error": "Validation failed",
    "details": [...]
  }


📦 BULK IMPORT FROM JSON
------------------------

Option 1: Create teams.json
  → Copy teams.example.json: cp teams.example.json teams.json
  → Edit teams.json with your team data
  → Run: node scripts/import-teams.js

Option 2: Use custom file path
  → node scripts/import-teams.js /path/to/your/teams.json

Expected output:
  ✅ Team Name (ID: 1)
  ✅ Another Team (ID: 2)
  ...
  🎉 All teams imported successfully!

⚠️  TROUBLESHOOTING
-------------------

Problem: "Missing Supabase credentials" in console
  → Add NEXT_PUBLIC_SUPABASE_URL and NEXT_PUBLIC_SUPABASE_ANON_KEY
    to .env.local
  → Restart dev server

Problem: "Failed to add team" (API returns 500)
  → Verify teams table exists in Supabase
  → Check credentials are correct
  → Look at browser console (F12) for errors

Problem: Connection refused (API not responding)
  → Ensure dev server is running: npm run dev:safe
  → Check port is 3006
  → Wait for "compiled successfully" message
