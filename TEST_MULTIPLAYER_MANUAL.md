# 🧪 MANUAL MULTIPLAYER TEST

## Инструкция для ручного тестирования (2026-04-28)

### Что мы исправили (FIX #2)
Заменили polling `setInterval` на встроенные Colyseus listeners:
- `room.state.players.onAdd()` - когда новый игрок присоединяется
- `room.state.players.onChange()` - когда игрок обновляет данные
- `room.state.players.onRemove()` - когда игрок уходит

Это дает **мгновенную синхронизацию** вместо задержки 16-48ms.

## РЕЗУЛЬТАТЫ (если всё работает)

✅ **УСПЕХ:**
- Оба игрока видны друг другу
- Движение синхронизируется в реальном времени
- Нет ошибок в консоли
- Нет "ghost" игроков

🟡 **ЧАСТИЧНЫЙ УСПЕХ:**
- Игроки видны, но есть задержка движения (500ms+)
- → Причина: медленная сеть или много логов в консоли
- → Решение: Отключить лишние console.log() (FIX #7)

❌ **НЕУДАЧА:**
- Игроки НЕ видны друг другу
- Ошибка WebSocket соединения
- → Логи: `[🔴 ERROR] Colyseus join failed`
- → Решение: Проверить console (F12) и server logs

## CONSOLE LOGS (что искать)

### Успешное подключение:
```
[🟢 COLYSEUS] Cleared old ghost players on join
```

### Ошибка подключения:
```
[🔴 ERROR] Colyseus join failed: ...  ← комната не доступна
[🔴 ERROR] Colyseus initialization failed: ...  ← сервер не отвечает
```

### Удаление игрока:
```
🔴 [COLYSEUS] Player left: {key}  ← игрок отключился
```

## ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Проверьте:
1. **Сервер работает?**
   ```bash
   curl http://localhost:3006
   ```
   Должен вернуть HTML

2. **WebSocket работает?**
   - Откройте F12 → Network
   - Фильтр: WS
   - Должно быть соединение с ws://localhost:3006

3. **Colyseus logs в серверной консоли:**
   ```
   [Colyseus] Basketball room created
   [Colyseus] Player PLAYER_NAME joining (sessionId)
   ```

4. **Очистите кэш браузера:**
   ```
   Ctrl+Shift+Delete или Cmd+Shift+Delete
   ```
