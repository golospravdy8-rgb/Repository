✅ WHAT WAS IMPLEMENTED

Three interconnected physics systems:

1. RIM COLLISION PHYSICS
   • Ball detects collision with front and back rim points
   • Normal vector reflection for bounce direction
   • 82% velocity retention (RIM_BOUNCINESS = 0.82)
   • 25% friction reduction (RIM_FRICTION = 0.25)
   • Prevents ball embedding in rim structure

2. BACKBOARD COLLISION PHYSICS
   • Ball detects collision with vertical backboard face
   • Bounce away from board (rightward)
   • 66% velocity retention (BOARD_BOUNCINESS = 0.66)
   • 38% friction reduction (BOARD_FRICTION = 0.38)
   • Enables bank shots and complex trajectories

3. GATE-BASED SCORING SYSTEM
   • Top Gate: Ball must enter from above (vy > 0)
   • Bottom Gate: Ball must exit downward
   • Two-part verification prevents false positives
   • Ball from below cannot score
   • Pure physics-based goal detection

🎮 PHYSICS BEHAVIOR

SCENARIO 1: Perfect Shot at Sweet Spot
  Input: Cursor at Sweet Spot (100% accuracy)
  Physics:
    1. Ball launches at ideal angle and speed
    2. Follows parabolic trajectory (gravity = 0.102 px/frame²)
    3. Passes through top gate from above (vy > 0)
    4. passedTopGate = true
    5. Continues downward
    6. Passes through bottom gate
    7. GOAL REGISTERED
  Output: "🎯 GATE GOAL!", net shake, score +2

SCENARIO 2: Rim Bounce Shot
  Input: Cursor 70% accuracy
  Physics:
    1. Ball trajectory approaches rim
    2. Collision detected: dist < BALL_RADIUS + RIM_THICKNESS
    3. Normal vector calculated from rim center
    4. Velocity reflected: v' = v - 2(v·n)n
    5. Friction applied: vx *= (1 - 0.25), vy *= (1 - 0.25)
    6. Bounce velocity: v' * 0.82
    7. Ball pushed out of rim
    8. Ball may re-enter gates from new trajectory
  Output: Visible bounce, possibly GOAL if trajectory aligns

SCENARIO 3: Backboard Bank Shot
  Input: Shot angled toward backboard
  Physics:
    1. Ball trajectory crosses x = BOARD_X face
    2. Y in range [BOARD_TOP, BOARD_BOT]
    3. Collision detected
    4. Ball.x = BOARD_X + BALL_RADIUS
    5. Ball.vx *= 0.66 (bounce away from board)
    6. Ball.vy *= 0.62 (friction reduces vertical)
    7. Ball continues toward hoop
  Output: Visible backboard impact, possible goal

SCENARIO 4: Undershooting
  Input: Low power shot
  Physics:
    1. Ball arc is too shallow
    2. Ball.y never reaches (HOOP_Y - 12px)
    3. Top gate check fails
    4. passedTopGate remains false
    5. Ball lands short, bounces on floor
    6. No scoring possible
  Output: No GOAL message, no score increase

SCENARIO 5: Ball from Below
  Input: Ball bounces upward from floor
  Physics:
    1. Ball has upward velocity (vy < 0 in canvas coords)
    2. Ball reaches top gate position
    3. Condition: b.vy > 0 (fails due to upward motion)
    4. passedTopGate NOT set to true
    5. Ball cannot satisfy goal condition
  Output: No false positive, ball bounces past

  RIM_BOUNCINESS = 0.82              // Velocity retention on rim
  RIM_FRICTION = 0.25                // Friction on rim
  RIM_THICKNESS = 4 * scaleX         // Rim collision depth
  BOARD_BOUNCINESS = 0.66            // Velocity retention on board
  BOARD_FRICTION = 0.38              // Friction on board

Rim Geometry:
  rimFront = { x: HOOP_X + HOOP_RADIUS, y: HOOP_Y }
  rimBack = { x: HOOP_X - HOOP_RADIUS, y: HOOP_Y }

Gate Positions:
  topGateY = HOOP_Y - 12 * scaleY
  topGateWidth = HOOP_RADIUS * 2.08
  bottomGateY = HOOP_Y + 22 * scaleY
  bottomGateWidth = HOOP_RADIUS * 1.82

Backboard:
  BOARD_X = 57 * scaleX
  BOARD_TOP = 189 * scaleY
  BOARD_BOT = 292 * scaleY
