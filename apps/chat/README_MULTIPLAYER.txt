🔧 КАК ЭТО РАБОТАЕТ:

СЕРВЕР (socketServerAdvanced.ts):
  1. Получить player_move от клиента
  2. Сохранить prevX, prevY (для интерполяции)
  3. Вычислить vx = (newX - oldX) / dt (dead reckoning)
  4. Каждые 50ms отправить game_state_update с:
     - x, y (текущая позиция)
     - prevX, prevY (для интерполяции)
     - vx, vy (для экстраполяции)
     - ballControlPoints (для мяча)

КЛИЕНТ (rucheyok-demo.html):
  1. Получить game_state_update
  2. Каждый фрейм вызвать updateRemotePlayerInterpolation()
  3. Вычислить displayX/displayY:
     - ИНТЕРПОЛЯЦИЯ (0-50ms):
       displayX = prevX + (x - prevX) * alpha
     - DEAD RECKONING (50ms+):
       displayX = x + vx * extraTime * 0.5
  4. Рисовать удаленных игроков с displayX/displayY (alpha=0.65)

МЯЧИК:
  1. Сервер отправляет контрольные точки: [{x, y, t}, ...]
  2. Клиент интерполирует между ними: pos = lerp(p1, p2, a)
  3. Результат: гладкая парабола при полете

📊 ПАРАМЕТРЫ НАСТРОЙКИ:

updateInterval = 50ms  (socketServerAdvanced.ts)
  → Частота обновлений с сервера (20 пакетов/сек)
  → Может быть 33ms (плавнее) или 100ms (экономнее)

extrapolationDamping = 0.5  (rucheyok-demo.html)
  → Затухание при dead reckoning
  → 0.3 = консервативнее, 0.7 = агрессивнее

remotePlayerAlpha = 0.65  (rucheyok-demo.html)
  → Прозрачность удаленных игроков при рисовании
  → Визуальное отличие от локальных
