## Проблема
На Vercel (basketball.lviv.ua/game/16) сторінка матчу показувала помилку:
- «Матч не знайдено»
- «Цей матч не існує або ще не відбувся.»

На localhost:3006 сторінка працювала ідеально.

## Корінь проблеми
Сторінка використовувала ISR (revalidate = 10) з кешуванням результатів на 10 сек.
Якщо при першому запиті гра не знайдена (з будь-якої причини) — 
результат кешується на 10 сек, блокуючи всі подальші запити.

Можливі причини "матч не знайдено":
1. Гра не існує в БД (дані не завантажені на Vercel)
2. Помилка Prisma запиту з-за проблем з БД

## Рішення (комміт 6231b53)
Оновив `/app/(public)/game/[id]/page.tsx`:
- Додав `export const dynamic = "force-dynamic"` для динамічного рендерингу
- Встановив `export const revalidate = 0` (без кешування)
- Додав try-catch блок з error handling

## Результат
Тепер сторінка:
- ✅ Не кешує результат "матч не знайдено"
- ✅ Завантажує свіжі дані з БД при кожному запиті
- ✅ Показує зрозумілі помилки при проблемах з БД

## Важливо для Vercel
Якщо на Vercel всі ще немає даних у БД:
- Перевір DATABASE_URL та PRISMA_DATABASE_URL встановлені на Vercel
- Вручну завантажи дані через admin панель, або
- Запусти seed: встанови ALLOW_SEED=1, потім деплой
