КРОК 1 — Vercel Dashboard (5 хвилин)
────────────────────────────────────────────────────────────────────────────

a) Перейди: https://vercel.com/dashboard/basket-lviv
b) Ліва панель → Storage → Blob
c) Натисни "Create" → назви "basketball-logos"
d) Три крапки (...) → "View Token"
e) Скопіюй токен (vercel_blob_rw_...)
f) Settings → Environment Variables
g) Add Variable:
   Name: BLOB_READ_WRITE_TOKEN
   Value: [вставь токен з кроку e]
   Environments: Production, Preview, Development
h) Save

✅ Готово на Vercel!


КРОК 2 — Локальне налаштування (2 хвилини)
────────────────────────────────────────────────────────────────────────────

Додай у .env.local:

   BLOB_READ_WRITE_TOKEN=vercel_blob_rw_...

Рестартуй dev сервер:

   npm run dev:safe


КРОК 3 — Локальне тестування (5 хвилин)
────────────────────────────────────────────────────────────────────────────

1. Відкрий: http://localhost:3000/admin/site-editor
2. Розділ "Команди"
3. Натисни на квадрат логотипу

5. Прогрес-бар, потім логотип з'являється
6. Натисни "Зберегти команду"
7. Перевір F12 Console → нема помилок
