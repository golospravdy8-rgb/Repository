🚨 IF SOMETHING GOES WRONG
═════════════════════════════════════════════════════════════════════════════

❌ Build fails
  1. Check logs: vercel logs --follow
  2. Check TypeScript: npm run lint
  3. Check env vars: vercel env list
  4. Redeploy: vercel deploy --prod

❌ "Environment variable undefined"
  1. Verify in Vercel Dashboard
  2. Re-run: vercel env list
  3. Redeploy: vercel deploy --prod

❌ "Supabase API error" or "Cannot connect to database"
  1. Check Supabase status: https://status.supabase.com
  2. Check Neon status: https://neon.tech/status
  3. Verify credentials in Vercel Dashboard
  4. Test locally: npm run dev:safe

❌ API returns 500 error
  1. Check logs: vercel logs
  2. Verify DATABASE_URL: vercel env list | grep DATABASE
  3. Check Supabase connectivity
