❌ IF SOMETHING GOES WRONG
═════════════════════════════════════════════════════════════════════════════

Dashboard still shows "Помилка дашборду":

  1. Check Vercel logs:
     vercel logs --follow

  2. Look for these errors:
     - ECONNREFUSED → Database offline (check Neon)
     - connect timeout → Pooler issue (wait 1 min)
     - Module not found → Missing dependency (rebuild)
     - Prisma error → Migration issue (check DATABASE_URL)

  3. If build failed:
     - Verify: DATABASE_URL in vercel env list
     - Verify: All Prisma types imported
     - Redeploy: vercel deploy --prod

  4. If database issue:
     - Check: https://neon.tech/status
     - Check: Database migrations applied
     - Test locally: npm run dev:safe

Build failed (never reached deployment):

  1. Check: npm run build (locally)
  2. Check: TypeScript errors
  3. Check: All imports present
  4. Look at: https://vercel.com/dashboard/basket-lviv → Deployments
  5. Click: Failed deployment → "View Logs"
